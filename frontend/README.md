# 💻 RescueMeal - Frontend Client

This is the frontend React client for the RescueMeal surplus food donation platform. It is built using **React (Vite)** and styled with **Tailwind CSS**.

For the comprehensive setup guide and system details, please refer to the main [Root README.md](../README.md).

---

## 🛠️ Technologies Used

*   **Vite + React.js:** High-speed development bundler and SPA framework.
*   **Tailwind CSS:** Modern utility styling.
*   **Lucide React:** Icon library.
*   **Axios:** Network requests to backend.
*   **Context API:** Handles global authentication and dark/light mode state.

---

## ⚙️ Environment Variables Setup

Create a `.env` file in this directory:

```env
VITE_API_URL=http://localhost:5000/api
```

---

## 🚀 Running Locally

Ensure dependencies are installed:

```bash
npm install --legacy-peer-deps
npm run dev
```

The frontend hot-reload server will start on [http://localhost:5173](http://localhost:5173).
